# install_package_options_RHEL_Ubuntu

To install any packages on your server, run below commands:
```
cd;sudo apt update -y > /dev/null 2>&1;sudo dnf install git -y > /dev/null 2>&1;sudo apt install git -y > /dev/null 2>&1;git clone https://github.com/nagaraj602/install_package_options_RHEL_Ubuntu.git > /dev/null 2>&1;cd install_package_options_RHEL_Ubuntu;bash install.sh;cd
```
